# 长卷 SVG zine 编辑器

一个**单文件、无依赖、离线可用**的本地编辑器。不上传任何内容，不联网。

```bash
# 直接双击打开（file:// 即可用）
open ~/.workbuddy/skills/wechat-animating-editor/app/zine-editor.html

# 若剪贴板 API 被浏览器限制，起本地服务再打开
python3 ~/.workbuddy/skills/wechat-animating-editor/scripts/serve.py
```

## 四个面板

| 面板 | 干什么 |
|---|---|
| **源码** | 粘/拖入 SVG；整理缩进、去注释、下载 .svg、复制源码 |
| **预览** | 375px 微信视口，卷轴滚动开关；播放/暂停 + 进度条 scrub |
| **体检** | 微信白名单与 SMIL 合法性实时检查（`validate_svg.py` 的 JS 版，规则一致） |
| **时间轴** | 甘特图：蓝=主时间轴动作，橙=常驻循环，绿=点击触发。点条跳转 |

## 为什么必须有 scrub

SMIL 动画写错不会报错，只会**不动**。肉眼在 22.3s 的循环里找"第 5 秒那条线没出来"极其费劲。进度条调 `svg.setCurrentTime(t)`，可以暂停后逐帧拖，把时序错误钉死在具体秒数上。

诊断顺序：

1. 预览里动画完全不动 → 看体检面板，`values`/`keyTimes` 段数不匹配是头号嫌疑
2. 动但时序错 → 拖进度条定位秒数 → 回去改 `timeline.json` 的 `at`/`dur`，重新编译
3. 点击没反应 → 确认元素初始 `visibility="hidden"`，且 `begin=click` 的 animate 有 `fill="freeze"` + `restart="always"`

## 发布

### 主路径（原生编辑器直接粘）

1. 编辑器里点「复制富文本」——同时写入 `text/html` + `text/plain` 双格式
2. 公众号后台 → 内容与互动 / 草稿箱 → **新建图文**，光标点到正文区，`Cmd+V`
   - 直接 `Cmd+V`（不是"从 Word 粘贴"）；粘完应该立刻看到长卷渲染出来
   - 一次只粘一个 SVG；别在同一段里混 Markdown 转换结果
3. 填标题 / 封面 / 摘要 / 原创声明——**长卷只是正文，标题封面要另配**
4. **正文里至少留一两句真实文字**（开头引子 + 结尾落款）：SVG 里的字不可选中、不可被微信搜索、读屏软件读不到
5. 「预览」→ 发送到手机，**真机确认**这四项：动画会动、点击有反应、字号够大、高度没塌陷
6. 存草稿 → 群发（或定时）

### 备用路径（粘进去被洗掉了时）

微信偶尔会二次清洗内联 `style`。症状与退路：

| 症状 | 说明 | 退路 |
|---|---|---|
| 长卷变成空白/只露一角 | 根 `svg` 上的 `style="display:block;width:100%;height:auto"` 被剥 | 用第三方编辑器（秀米 / 135 / i排版 / 壹伴）的「HTML 源码」入口整段粘，比直接粘富文本更稳 |
| 动画全不动 | 清洗时动了 `animate` 的 `keyTimes`/`values` | 换路径重粘；粘完在草稿里再开一次体检确认标签还在 |
| 只显示上半截 | 单卷过高（>20000px）或源码 >1MB | 拆成 2~3 段 SVG，分段粘进正文 |

### 真机验收清单

- [ ] 自动播放的叙事段能完整走完（不是只看到前面几屏）
- [ ] 点击段有文字提示，且点了确实有反应
- [ ] 字号在真机上不小于 11px（设计稿 750 宽下 ≥22）
- [ ] 长卷底部没有被裁切
- [ ] 关掉 WiFi 用 4G 打开一次，确认加载体积可接受（建议源码 <500KB）

### 发布后

- 长卷内容**不可被搜索、不可选中**，所以标题和摘要要自己把信息说清楚
- 读者长按无法保存 SVG；若要留存，另发一版静态长图或 PDF

## 与 doocs/md 的分工

`doocs/md`（13.3k 星）做的是 **Markdown → 微信富文本**，强在主题与代码块排版，**不产 SVG 长卷**。本编辑器只做长卷 SVG 这一件事：预览、体检、时序调试、粘贴。两者互补，不冲突——正文里既有 Markdown 段落又有 zine 长卷时，先用 doocs/md 出正文，再把本编辑器的 SVG 以 HTML 源码方式插进去。

## 已知限制

- 只处理**单个**外层 `<svg>`；多段 SVG 请逐段检查
- 预览用系统字体渲染，与 iOS 真机可能有细微字宽差异
- 剪贴板 API 需 secure context；`file://` 通常可用，被拦时改用 `serve.py`
- 不做 SVG 可视化绘制（不是矢量绘图工具），源码由 `wechat-animating-authoring` 产出
