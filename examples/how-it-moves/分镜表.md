# 《它是怎么动起来的》分镜表

**母题**：纸本 Kraft（`#efe8d8` 纸 / `#1c1b18` 墨 / `#d4532a` 砖红 / `#857f73` 灰）+ 终端元素（Menlo 等宽）
**母题符号**：6 辐条节点（样本文章的招牌图形，全卷重复出现）
**骨架**：叙事弧 —— 先复刻"它长什么样"，再推演"它怎么做出来的"
**长度**：10 屏 × 700 = 750 × 7000
**主时间轴**：22.3s（与样本文章同周期，作为致敬）

| 屏 | 视觉主体 | 文字 | 动作 |
|---|---|---|---|
| P1 | 通栏标题 + 水印"然而" | 它是怎么动起来的 / 一份关于长卷 SVG 的技术小报 | 标题 fade-in 0→2.0s；副题 rise 2.2→1.4s；节点 flicker 常驻 |
| P2 | 三行删除线 + 一行强调 | 不是视频 / 不是 GIF / 不是图片 / **是一段 SVG** | 三行 appear 依次 3.6/4.2/4.8s；强调行 fade-in 5.8→1.4s；代码块 6.6→1.6s |
| P3 | 终端对话框 | ASSISTANT: 你好。（**复刻样本第 2 屏**） | appear 8.0→1.6s；光标 blink 常驻 1.1s |
| P4 | 4 节点 + 提示语 | [ 点一下，看它们在看谁 ]（**复刻样本交互幕**） | **click** draw-stagger 0.12s ×4；节点 breathe 常驻 |
| P5 | 大问号 + 转折 | 可是，怎么做的？ | fade-in 11.0→1.8s；问号 swing 常驻 |
| P6 | 三个输入盒 → 一个输出 | skeleton.svg / timeline.json / compile → zine.svg | 三盒依次 wipe 12.6/13.2/13.8s；箭头 draw 14.6→1.4s |
| P7 | keyTimes 算式 | at 3.4s, dur 1.6s → keyTimes="0;0.1525;0.2242;1" | 数字打字机 stagger 16.2→；结论行 17.6→1.4s |
| P8 | 注入前后对照 | `<g data-cue="hero">` → 插入 `<animate>` | 左盒 appear 18.4；右盒 appear 19.0；箭头 draw 19.6→1.2 |
| P9 | 嵌套三层 + 热区 | 点热区 → 冒泡穿过每一层 → 各层同时 begin | **自动播放演示**：气泡上升 + 三层依次亮 + 三线依次生长 20.0→ |
| P10 | 体检清单 + 发布三步 | 0 error / 0 warn → 375px 预览 → 真机 → 粘贴 | 清单逐条 appear stagger；发布三步 wipe |

## 三条自查

- 每屏 1 个视觉主体、≤2 个主动作 ✓
- 交互点（P4）放在读者已积累好奇之后（前 3 屏先建立情境），且有文字提示 ✓
- 常驻循环用不同 dur（1.1 / 3.6 / 4.2 / 2.6s），错开避免节拍感 ✓
