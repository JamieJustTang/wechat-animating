# 长卷 zine 的视觉与分镜

**先定风格母题，再写分镜表，最后才碰源码。** 顺序反了会出现"每个元素都不错、整卷不像一回事"——这是长卷最常见的死法。

## 一、六套风格母题

一套 zine 只能用一套。混搭即翻车。

| 母题 | 纸色 | 墨色 | 强调色 | 字体 | 装饰语法 | 适合题材 |
|---|---|---|---|---|---|---|
| **纸本 Kraft** | `#efe8d8` | `#1c1b18` | `#d4532a` 砖红 | 宋体标题 + 黑体正文 | 纤维噪点、撕边、手写箭头、胶带 | 随笔、手记、人物 |
| **终端 Terminal** | `#f7f6f3` 或 `#111` | `#1c1b18` | `#3B6D11` 磷绿 | 全等宽 Menlo | 光标块、`>` 提示符、`[ ]` 标签、进度条 | 技术、AI、对话体 |
| **Riso 印刷** | `#f4f1ea` | `#2C2C2A` | 两色叠印（如 `#D4537E` + `#378ADD`） | 粗黑体 | 半调网点、套印错位、正片叠底 | 观点、宣言、概念 |
| **报纸 Letterpress** | `#faf8f3` | `#1a1a1a` | 无（靠墨色层次） | 宋体全篇 | 分栏、规则线、首字下沉、通栏大标题 | 综述、评论、考据 |
| **蓝图 Blueprint** | `#185FA5` | `#E6F1FB` | `#FFFFFF` | 等宽 + 细黑体 | 网格底、尺寸标注线、剖面阴影 | 架构、流程、系统拆解 |
| **瑞士网格** | `#ffffff` | `#111111` | 单一饱和色（`#E24B4A` / `#BA7517`） | 无衬线粗体 | 16 栏栅格、大量留白、巨型字号对比 | 数据、清单、论证 |

### 配色纪律

```
1 纸色（背景） + 1 墨色（正文） + 1 强调色（点睛） + 1 灰（次要信息）
```

强调色的**使用面积不超过 5%**。它是感叹号，不是涂料。样本文章把 `#d4532a` 用在：小标题、节点圆心、连线、几个词——整卷 11980px 高，砖红面积极小但每个视觉锚点都是它。

灰色的标准做法：墨色 + `opacity="0.45~0.6"`，不要另调一个灰 hex，这样整卷色调自动统一。

**但只有 4 色是不够的**。样本实测有 **12 种颜色**：5 档纸灰（`#efe8d8 / #f3eee2 / #ebe4d4 / #d8cfb9 / #cfc7b6`）+ 2 档墨（`#1c1b18 / #171614`）+ 3 档灰（`#857f73 / #b8b0a0 / #9a9384`）+ 1 强调。层次感来自**同色系的细微深浅差**，不是来自多色。

### 字号阶梯（750 稿宽，手机 375 显示即 ÷2）

| 用途 | 字号 | 手机实际 |
|---|---|---|
| 通栏大标题 | 64~84 | 32~42px |
| 章节标题 | 40~48 | 20~24px |
| 正文 | 26~30 | 13~15px |
| 次要/注释 | 22~24 | 11~12px |
| 等宽标签 | 20~22 | 10~11px |

**下限 22**（手机 11px）。低于此在微信里不可读，不要为了排版好看牺牲它。

行距：正文行高 = 字号 × 1.5~1.7。长卷没有滚动阻尼，行距要略大于常规网页。

### 视觉密度：小报感 vs 海报感（决定"好看"的关键）

样本实测：`22px` 用了 **220 次**、`rect` 475 个、`path` 447 条、虚线 **68 处**（`5 4` / `1.5 5` / `2 5` 等多种规格）、`17px` 微标签 17 处。它靠**密集的小字、细线、刻度、角标**营造"技术小报"的精密感——而不是大标题 + 稀疏正文的"海报感"。

最小装饰系统（照做就能上密度）：

| 装饰 | 做法 |
|---|---|
| 纸纹噪点 | 随机短斜线 300 条 / 全卷，`opacity 0.05~0.2` |
| 水印词铺底 | **12 个**大字号（54~80）低透明度（.045~.06）转折词，间隔约一屏一个 |
| 节点网络 | 9 个低透明度母题符号散布全卷 |
| 虚线 | 分隔线、引线、圈选用不同 dasharray |
| 刻度尺 | 一排细竖线（每 5 格加长）+ 端头数字 |
| 进度块 | 小 rect 序列（8×16，间距 11），页脚标配 |
| 伪 UI 标签 | 等宽 17px 小字 + 细框（`CTX 35%`、`P.02` 那类） |
| 角标 | L 形细线钉在卡片四角 |
| 坐标标注 | 图形旁标 `(x, y)` 等宽小字，工程图味 |
| 手绘箭头 | 带弧度的 Q 曲线 + 分叉箭头，端点不闭合 |
| 手绘圈选 | 两条略错位的椭圆弧，不闭合 |
| 印章 | 双框轻微错位（模拟盖歪）+ 等宽字 |
| 斜线网纹 / 半调网点 | 区块填充（riso 感），需 clipPath 裁切 |

判断标准：把源码体积除以画布面积，样本约 **0.34 KB / 千像素高**——低于这个量级就会显得空。

## 二、分镜：以「屏」为单位

**一屏 = 750 × 1200~1334**（手机一屏的高度）。整卷长度 = 屏数 × 1200。样本文章 11980 ÷ 1200 ≈ **10 屏**——这是一个舒服的长度，别轻易超过 16 屏。

### 分镜表模板（写源码前必须先有这张表）

| 屏 | 视觉主体 | 文字 | 动作（at → dur） | 备注 |
|---|---|---|---|---|
| 1 | 通栏大标题 + 副题 | "一份从上下文窗口…" | 标题 fade-in 0→1.8s；副题 rise 1.6→1.2s | 留白 ≥ 40% |
| 2 | 终端对话框 | "ASSISTANT: 你好。" | appear 3.4→1.6s；光标 blink 常驻 | 光标闪烁从第 2 屏开始 |
| 3 | 节点图 + 提示语 | "[ 点一下，看它们在看谁 ]" | 连线 **click** draw-stagger 0.12s | 交互点 |
| … | | | | |

**写表的三条规矩**：

1. 每屏只许有 **1 个视觉主体** + **至多 1 个主动作**。两个主体 = 读者不知道看哪。
2. 文字 ≤ 40 字/屏（正文）。长卷是扫读媒介，不是阅读媒介。
3. 每屏必须回答"读者为什么往下滑"——靠悬念、靠视觉牵引（箭头、连线、视线方向）、靠留白节奏。

### 五种叙事骨架

| 骨架 | 结构 | 适用 |
|---|---|---|
| **叙事弧** | 平静 → 扰动 → 加剧 → 转折 → 落定 | 故事、经历、案例 |
| **问答式** | 提一个问题 → 一屏一答 | 科普、FAQ、概念澄清 |
| **推演式** | 前提 → 一步步推 → 结论 | 论证、分析、技术拆解 |
| **清单式** | 总起 → N 个并列条目 → 收束 | 盘点、资源、要点 |
| **对照式** | 左/右 或 前/后 逐项对撞 | 对比、评测、反转（H1 假说那种） |

样本文章用的是**叙事弧**，靠"然而/但是"水印层做暗线——重复的低频词在纸底反复出现，读到最后才发现那是全文的转折节奏。这个手法很省成本，值得抄。

## 三、让矢量插画"活"起来的最低成本手法

不需要会画画。以下全是几何图形 + 循环动画：

| 手法 | 做法 | 成本 |
|---|---|---|
| **呼吸** | 整个 `<g>` 挂 `translate 0 0 → 0 -12 → 0 0`，3.6s | 低 |
| **眨眼** | `opacity 1;1;0;1;1` @ `0;.92;.95;.98;1`，4.2s | 极低，**效果最显著** |
| **钟摆** | `rotate -8 cx cy → 8 cx cy → -8 cx cy`，2.6s | 低 |
| **光标** | 一个 `<rect>` 挂 `blink` 1.1s | 极低 |
| **纸纹** | 一堆 `opacity=".045"` 的词/点/线条散布 | 中，但一次做完 |
| **伪 UI 标签** | `CTX 35%`、`[空]`、`→` 之类的等宽小字 | 极低，真实感提升明显 |
| **网络节点** | `circle` + 6 条辐条 `path`（`stroke-linecap="round"`，粗描边） | 低，可做母题符号 |

**母题符号**：全卷重复出现同一个简单图形（如一个 6 辐条节点），把它当 logo 用。样本文章全卷用了不下十次这个节点，是它视觉统一的最大功臣。

## 四、动效配比与交互放置

- **主动作密度**：每屏 ≤ 2 个（多了像车祸现场）
- **主时间轴周期**：= 全卷读完的时间，一般 **15~30s**。太短视频化，太长读者等不及
- **常驻循环**：全卷 ≤ 5 处，且用**不同的 dur**（3.6 / 4.2 / 2.6 / 1.1s），错开后不会有节拍感；用同一个 dur 会像节拍器
- **交互点放置**：放在读者**已经积累好奇之后**（样本放在第 3 屏，前两屏先建立情境），且**必须有文字提示**。没提示的点击区 = 零交互
- **不要做的事**：全屏闪烁、超过 20% 面积同时运动、给正文文字加动效（会晕）

### 关键区分：叙事性动画 vs 演示性动画

主时间轴的"依次出现"有一个固有缺陷：**动画与滚动不同步**。在 T 秒周期里第 t 秒出现的元素，可见时间只有 (T−t)/T——排在后面的屏，读者滚到时大概率还没出现，或者已经闪过。

所以分镜时要分两类处理：

| 类型 | 挂哪 | 例子 |
|---|---|---|
| **叙事性**（出现一次然后保持） | 主时间轴，时刻 ∝ 屏位置 | 标题浮现、章节入场 |
| **演示性**（讲一个反复发生的过程） | **独立短循环**（4~7s），滚到就看得见 | 原理演示、流程重演、对比动画 |

一句话判据：**读者错过它会不会可惜？** 会 → 主时间轴；不会、看一眼就懂 → 独立循环反复重演。
